# Minecraft Personality Quiz

A lightweight, responsive personality quiz that finds out whether you play like a
Fighter, Miner, Builder, or Farmer.

## Run it

Open `index.html` in a browser. The quiz uses plain HTML, CSS, and JavaScript and
does not require a build step.

## About

Answer five questions to get a role and a short description of your strengths.
The quiz is fan-made and is not affiliated with or endorsed by Mojang or Microsoft.
